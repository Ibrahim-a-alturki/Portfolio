# Oracle APEX Application

This folder contains screenshots of the Vehicle Insurance Portal's interactive front-end, built in Oracle APEX and connected to the schema in [`../sql/`](../sql/).

See the [`screenshots/`](screenshots/) folder for previews of each page:

- Owner's Information Entry (create form)
- Owners Details (records grid)
- Policies & Coverages
- Policies By Vehicle
- Claims By Policies
- Claims Dashboard

For the full write-up of each page's features, see the [main README](../README.md#-oracle-apex-application).
